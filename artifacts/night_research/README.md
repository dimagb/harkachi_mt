# Ночные эксперименты — происхождение финального ML-релиза

Это сохранённые результаты исследовательской сессии 27.09.2026, а не новая
оценка независимой выборки. Даты проверок пересекаются; 2054 строки оценок,
69 формулировок и 192 сочетания модели/веса не равны числу независимых испытаний.

Текущий релиз — `hackathon-v8`, score 0.90268, точный MD5
`a2a872c04316e64e41ad2ac7940cd45c`. Оценки сообщены пользователем; соответствие
порядку рекомендованных CSV записано в `user_submission_scores.json`.
Окончательное описание — `README_ML.md`, параметры — `configs/final_model.json`.

`SUMMARY_RU.md` сохраняет состояние на завершение ночной сессии: тогда
скрытые оценки ещё не были известны, релиз не изменялся. Это историческая
запись, пути `night/session_20260927/` в ней относятся к локальному полному
журналу, который в поставку не нужен. Позднее пользователь сообщил оценки
и разрешил перенос лучшего кандидата в основную ML-часть.

`fare_components_scores.csv` содержит исправленные сравнения по типам билетов.
`fare_shape_ensemble_scores.csv` — предварительный ансамбль: C/D рассчитаны
до выравнивания начала обучающей истории и не считаются окончательным доказательством.
Этот ансамбль в текущий релиз не включён.

Компоненты выбранного Chronos, манифесты и исторические остатки находятся в
`artifacts/chronos/`. Там же отдельно зафиксировано ухудшение весеннего фолда D;
общий положительный результат не выдаётся за улучшение каждого периода.
