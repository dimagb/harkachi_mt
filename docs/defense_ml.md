## Модель и обучение

База — уровень дня из последних четырёх чистых недель того же сезонного режима
× медианный почасовой профиль × календарь, с поправкой на световой день.
Параметры базы оцениваются по labels января–октября 2025.

Новая нейросетевая часть — pretrained Chronos-2, frozen zero-shot, Apache-2.0.
На частных данных веса не дообучаются. Медиана дневного прогноза и 24 часовых
канала получают известные календарные признаки, астрономию и события сети.
25% дневного объёма и 25% нормированных долей часа берутся из Chronos;
остальное из базы. Ограничение дневного отношения: 0.25–2.

7/50: обычное движение по выходным восстановлено 15 ноября, по
[официальному источнику](https://t.me/DtOperativno/23565).
Маршрут 5: до 16 декабря 18:00 нули, затем 0.7 × статистический маршрут 25;
это ранее выбранный prior, не оценка реального скрытого потока.

Исторические проверки: четыре фолда, восемь скользящих срезов февраля–сентября,

+0.002301 на днях 31–60, оба осенних среза положительные. Все восемь скользящих
срезов положительные; весенний фолд D ухудшается на 0.002635. Не утверждаем,
что модель улучшает любой возможный период. Пересекающиеся цели использовались
для исследовательского отбора; дальнейший перенос на зиму не гарантировался.

Проверены TimesFM, Bolt, Granite, TabICL, LoRA, DLinear/PatchTST, GP,
когорты карт, ансамбли, погодные методы и заболеваемость. Крупного устойчивого
прорыва до 0.95 не найдено. Последний ансамбль по типам билетов не завершил
сопоставимую проверку и не включён.

## Доступность данных

Сданный релиз явно EX_POST: использует официальные объявления после 31 октября
и прежнюю калибровку ×1.012. `production` ограничивает published_at датой среза,
не использует leaderboard-калибровку и не видит позднее уточнение ремонта.
Ревизии событий сохраняют раннюю информацию для исторических прогнозов.
Приватные ноябрьские/декабрьские метки, реальные вагоны и производные скрытого
спроса не становятся признаками. Реальная будущая погода в релиз не входит.

## Воспроизведение и продукт

```bash
python -m pip install -r requirements-ml.txt
python -m ml.build_release --data service/data --submission release/submission.csv
python -m ml.verify_release
```

Данные и проверенные компоненты инференса включены в проект: сырые файлы,
ночная папка, PyTorch и сеть для offline-build не нужны. Новый inference:
`requirements-foundation.txt`, затем `python -m ml.refresh_chronos`.
Pinned ревизия и хеши входов в `artifacts/chronos/`; при изменении входов
нельзя тихо взять старые компоненты. Score показывается только при совпадении MD5.

Сервис читает этот же CSV; тяжёлая модель на веб-запросах не запускается.
What-if и ручные сетевые события применяются поверх model_prediction.
Измеренный вторичный эффект 17 → 11 ×1.1079 только по выходным сохраняется.
Интервалы эмпирические; на маршруте 5 нет истории для проверки их покрытия.
Цикл JSON-приём → runtime.duckdb → пересборка пока не замкнут.

Прежний релиз сохранён в `release/archive/hackathon-v7/`. Производительность
сервиса из предыдущих испытаний не объявляется новым нагрузочным замером модели.
