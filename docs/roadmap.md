подтверждены календарь, световой день, ремонты — в прогнозе; погода —

не заявляется.

**События сети** — `FULL_CLOSURE`, `SHORTENING`, `MANUAL_MULTIPLIER`,
`GET` / `POST` / `DELETE /api/network-events`, массив `network_events`
в ответах, значения уже пересчитаны. Вторичный эффект 17 → 11 × 1.1079
только в выходные. Плашка на графике — в запасном дашборде.

**Сценарии** — коэффициенты `k_*` в `GET /api/forecast`,
`POST /api/forecast/preview` с опциями из каталога релиза, базой,
сценарием и разложением по шагам.

**Приём потока** — `POST /api/ingest/validations`, идемпотентность,
агрегаты; цикл до пересборки не замкнут (см. выше).

**Воспроизводимость** — релиз собирается из репозитория без сырых данных,
md5 совпадает с прогнозом, получившим скор (`README.md`, «Быстрый старт»).

**Бизнес-ценность** — блок рекомендаций в запасном дашборде; в питче —
распределение подвижного состава, снижение переполнения, уточнение
