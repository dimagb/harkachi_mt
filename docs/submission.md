## Канал 1 — CSV на лидерборд (раздел Data Science)

Лимиты: 36 попыток в день всего, 24 успешных. **В зачёт идёт лучший
результат за всё время** — ухудшить нельзя, отправлять можно смело.

- [ ] Разделитель `;`, кодировка UTF-8, заголовок обязателен
- [ ] Колонки строго: `route;date;hour;prediction`
- [ ] `route` из набора `1,5,7,11,12,17,25,26,28,50`
- [ ] `date` в формате `YYYY-MM-DD`, от `2025-11-01` до `2025-12-31`
- [ ] `hour` целое `0…23`
- [ ] `prediction` число ≥ 0
- [ ] **Ровно 14 640 строк**, полная сетка без пропусков
- [ ] Маршрут 5 — нули на всём периоде (осознанный выбор релиза, см. ниже)
- [ ] Нет дублей по ключу `route, date, hour`

Проверка перед отправкой (чистый Python, без зависимостей):

```python
import csv
from collections import Counter

rows = list(csv.DictReader(open("submission.csv", encoding="utf-8"), delimiter=";"))
assert list(rows[0]) == ["route", "date", "hour", "prediction"], list(rows[0])
assert len(rows) == 14640, len(rows)
assert all(float(r["prediction"]) >= 0 for r in rows)
assert {int(r["route"]) for r in rows} == {1,5,7,11,12,17,25,26,28,50}
assert all("2025-11-01" <= r["date"] <= "2025-12-31" for r in rows)
keys = Counter((r["route"], r["date"], r["hour"]) for r in rows)
assert max(keys.values()) == 1, "есть дубли"
# Маршрут 5 в сданном релизе нулевой на всём периоде — осознанный выбор,
# а не ошибка сборки. Ненулевое значение значит, что в файл попал не тот релиз.
five = [r for r in rows if r["route"] == "5"]
assert len(five) == 61 * 24, "маршрут 5 должен быть в сетке"
assert sum(float(r["prediction"]) for r in five) == 0, \
    "маршрут 5 в сданном релизе нулевой на всём периоде"
print("OK")
```

**Маршрут 5 — почему нули.** Маршрут запущен 16.12.2025, истории нет.
Находка обнаружена и измерена: прогноз с cold start от аналога с 16 декабря
дал на лидерборде 0.89447, тот же прогноз с нулями по маршруту 5 — 0.88987,
то есть cold start стоит +0.0046. В сданный релиз ML-команда взяла
консервативный вариант с нулями. Оба варианта выше 0.88 и дают одинаковый
максимальный балл.

**Два числа, оба верны:**

| Число | Что это |
|---|---|
| **0.89447** | лучший результат команды на лидерборде; в зачёт идёт лучший за всё время, по нему оценивается критерий 1 |
| **0.88987** | скор прогноза, который лежит в репозитории, отдаётся сервисом и воспроизводится кодом |

Модель заморожена: в поле 1 идёт коммит, конфиг и сид, воспроизводящие
релиз со скором 0.88987.
