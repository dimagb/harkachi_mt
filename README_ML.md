# ML: финальный релиз 0.90268

Почасовой прогноз успешных валидаций на 10 маршрутах, 1 ноября — 31 декабря 2025.
Один релиз содержит 14 640 значений; DuckDB, CSV для сдачи и CSV сервиса совпадают.

## Модель

Статистическая декомпозиция оценивает медианный уровень последних чистых недель
того же режима и доли часов, учитывает календарь и световой день. Chronos-2
(`amazon/chronos-2`, Apache-2.0), ревизия
`29ec3766d36d6f73f0696f85560a422f50e8498c`, работает zero-shot без дообучения
на частных данных. Вход — только labels до среза и календарь/астрономия/события.

Для каждого маршрута и дня:

```
объём = baseline_day × (0.75 + 0.25 × clip(chronos_day / baseline_day, 0.25, 2))
доля часа = 0.75 × baseline_share + 0.25 × normalized_chronos_hour
прогноз = объём × доля часа × 1.012
```

Для малых baseline_day ≤ 100 отношение объёма равно 1. Отрицательные почасовые
предсказания Chronos обрезаются до 0. Маршрут 5 не корректируется Chronos:
до 16.12.2025 18:00 нули, затем prior 0.7 × статистический маршрут 25.

7/50 возвращаются к обычному выходному режиму 15 ноября по
[официальному объявлению](https://t.me/DtOperativno/23565). В CSV событий
сохранены раннее объявление и позднее уточнение с одинаковым стабильным ключом.

## Режимы и правила доступности

- `leaderboard` — явно EX_POST: поздние официальные объявления и старая
  калибровка ×1.012. Это сданный кандидат 0.90268.
- `production` — только объявления с published_at ≤ cutoff, без калибровки.
  Для среза 31 октября маршрут 5 остаётся нулевым. Проверенный строгий CSV
  получил 0.89011; это другой прогноз, ему не присваивается score 0.90268.
- Ноябрьские/декабрьские целевые валидации, наблюдённые вагоны и производные
  скрытого спроса не являются признаками. Фактическая будущая погода в релиз не вошла.

## Сборка и проверка

Python 3.12, отдельное окружение. `requirements-ml.txt` фиксирует версии
вычислительных библиотек. Установка зависимостей требует сеть; сам офлайн-build — нет.

```bash
python -m pip install -r requirements-ml.txt
python -m ml.build_release --data service/data --output release/forecast_release.duckdb --submission release/submission.csv
python -m ml.verify_release
TRAM_DATASET=service/data python -m pytest tests -q
```

На Windows установите `$env:TRAM_DATASET='service/data'` перед pytest.
`--require-clean` добавляется после коммита; незакоммиченная интеграция имеет
code_git_sha с суффиксом `-dirty`, чистая версия кода не выдумывается.
После новой сборки CSV сервиса обновляют копированием `release/submission.csv`
в `service/data/submission.csv`; при работающем сервисе затем `POST /api/reload`.

`artifacts/chronos/leaderboard_20251031.csv` — компоненты инференса, а не скрытые
метки. Манифест проверяет их SHA256, историю, источники и горизонт. Изменение
входов требует нового инференса, тихого переноса старого прогноза нет.

## Повторный инференс

```bash
python -m pip install -r requirements-foundation.txt
python -m ml.refresh_chronos --data service/data --mode leaderboard
python -m ml.build_release --data service/data --submission release/submission.csv
# Для нового периода: --cutoff / --from / --to и --mode production
# Для обхода snapshot при сборке: --recompute-foundation
```

Весов 478 МБ в git нет; pinned ревизия скачивается в `.ml-cache/`.
`--model-path` у refresh_chronos позволяет использовать локальную копию весов.
Повторный inference выполнен на CPU float32; перенос на другое железо может
изменить младшие разряды, поэтому скор привязывается к MD5, а не названию модели.

## Результаты

| Вариант | Скор, сообщённый командой |
|---|---:|
| Предыдущий лучший | 0.89447 |
| Исправление движения + прежний prior маршрута 5 | 0.90054 |
| То же + Chronos, текущий релиз | **0.90268** |
| Строгий Chronos | 0.89011 |

Вклад нового ML при одинаковом событийном сценарии: +0.00214.
Общий прирост относительно прежнего лучшего: +0.00821. На восьми скользящих
проверках прирост Chronos, взвешенный по фактическому объёму, +0.003721,
на днях 31–60 +0.002301. A/B: +0.000191/+0.002131; D ухудшается на 0.002635.
Это исследовательский выбор на пересекающихся датах, а не независимые испытания.

Исследовано 69 формулировок, 192 сочетания модели и веса, 2054 строки оценок.
Краткий журнал и результаты — `artifacts/night_research/`. Незавершённый
ансамбль типов билетов не вошёл в релиз. До 0.95+ подтверждённого результата нет.

## Артефакты для сдачи

- `release/submission.csv`: MD5 `a2a872c04316e64e41ad2ac7940cd45c`.
- `release/forecast_release.duckdb`: model_prediction, метаданные, what-if,
  измеренные сетевые правила и эмпирические интервалы.
- `service/data/submission.csv`: тот же CSV, который читает сервис.
- `configs/final_model.json`, `configs/release.json`: модель, режим, score и хеш.
- `artifacts/chronos/`: offline inference, манифесты и rolling-остатки.
- `release/archive/hackathon-v7/`: прежний релиз и его конфигурация.
- `docs/defense_ml.md`, `docs/submission.md`, `release/CONTRACT.md`: защита и сдача.

Интервалы оценены по историческим остаткам этого ансамбля; у маршрута 5 нет
наблюдений до среза, перенесённый интервал его качества не подтверждает.
При обновлённой истории до новых hybrid-backtests используется статистический
интервал-прокси. Онлайн-приём JSON и offline runtime.duckdb пока не соединены.
