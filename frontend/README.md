# Диспетчерская трамваев Москвы

React + JavaScript + Vite. Экраны: `/login`, `/dashboard`, `/analytics`.

## Запуск

```sh
npm ci
npm run dev
```

Открыть http://localhost:5173. Vite проксирует `/api` на `http://localhost:8000`, как предусмотрено исходным контрактом. В клиенте используются только относительные `/api/...`; адрес бекенда в переменных окружения не нужен.

Для просмотра без бекенда: http://localhost:5173/login?demo=1. Деморежим явно обозначен в шапке и не включается автоматически при ошибках API. Чтобы выключить: удалить `tram-demo` из sessionStorage или открыть новую приватную сессию. Демо не выдумывает геометрию маршрутов и не отправляет административные команды. Выгрузка реального XLSX требует бекенд.

Вход — локальное переключение роли, API не защищается вымышленными токенами. Можно нажать «Войти в систему», не заполняя поля. Допустимые демонстрационные логин/пароль: dispatcher / dispatcher (не являются механизмом защиты). Административная форма доступна через меню пользователя после выбора роли «Администратор».

## Сборка и интеграция

```sh
npm test
npm run build:service
```

Команда собирает `dist/`, заменяет содержимое `service/static/` и сохраняет `.gitkeep`. После этого `cd ../service && docker compose up --build` запускает бэкенд и фронтенд на одном порту 8000. Используется штатный `service/Dockerfile` из main: он копирует готовую статику и не запускает Node.js. `npm run build` отдельно создаёт только `dist/` и не обновляет Docker-сборку. SPA fallback для `/login`, `/analytics`, `/dashboard` реализован бэкендом. `Dockerfile.example` — необязательный альтернативный пример; текущий Compose его не использует.

## Контракт

Коэффициенты отправляются с debounce 180 мс в `/api/forecast/preview`: ответ содержит базу, сценарий и изменение. Для XLSX и остановок произведение факторов `explain` передаётся как `k_global`; события сети повторно не применяются. Геометрия сохраняет обе линии направлений и порядок `[lon,lat]`; обратная линия видна с масштаба 14. Оговорка об оценочной разбивке берётся из `note`, остановки — из `name`, список отсутствующей геометрии — из `routes_without_geometry`. Подпись маршрута 5 берётся из `/api/routes.note`, значение прогноза определяет текущий релиз.

Интерфейс подключён к живому API. `/meta` заполняет состояние данных, `/factors.options` — сценарии, `/forecast/routes` — рейтинг. История и прогноз загружаются через `/forecast`; `/forecast/compare` и `/scope` UI не вызывает. При отсутствии метрики точности показывается «—», а не выдуманный процент. Погодная телеметрия и операции добавления вагонов не описаны в API: действия показывают честное уведомление и не объявляют команду отправленной.

## Поведение экранов

- Диспетчерская: карта, часы и даты, мультивыбор маршрутов, фильтр относительной нагрузки, коэффициенты, почасовой график и XLSX. Горизонты «День / Месяц / Год» — только в параметрах аналитики.
- Цвет маршрута: средний поток выбранных часов относительно его пикового часа за тот же период, границы 25/50/75%. Это не доля в потоке всей сети и не заполненность вагона.
- Цвет участков выбранного маршрута: среднее оценочных `value` соседних остановок относительно квартилей базового прогноза направления. Поправки меняют значения при фиксированных базовых порогах. Это не сумма посадок на произвольном участке.
- «Показать остановки» показывает точки всех видимых маршрутов. Клик по маршруту выделяет его, клик по остановке показывает название и синхронизирует выбор в «Ситуации». Список остановок открывается отдельной кнопкой под графиком или из рейтинга/ленты событий.
- Рейтинг охватывает все маршруты и все часы за пересечение выбранных дат с прогнозом; это подписано в таблице. Рекомендации отбирают два маршрута по базовому объёму с учётом фильтра маршрутов, но без фильтра часов и сценарных поправок.
- «Факторы прогноза» — справочная плашка. Каталог измеренных источников, окно `/scope`, отдельные списки `adjustments`, `secondary_effects` и `warnings` пока не представлены в UI. Они остаются доступными в API; не считать их показанными на экране.

Карта: MapLibre + [OpenFreeMap](https://openfreemap.org/quick_start/), центр Москвы. Спутниковые снимки OpenFreeMap не предоставляет, поэтому кнопка «Спутник» убрана по просьбе пользователя. Декоративные логотип и трамвай показываются из предоставленных пользователем изображений. Фон авторизации — отдельное изображение без нарисованной формы; поверх него отображается действующая HTML-форма.

Приоритет требований: уточнение пользователя о контракте и оценке; затем предоставленные пять макетов. Схемы компоновки и предложение изменить экран входа в исходном markdown не заменяют пользовательские макеты.

## Проверки

Автотесты контракта: периоды, високосный февраль, имена параметров, сохранение диапазонов коэффициентов, относительные запросы, ошибки API, отсутствие повторного применения событий сети. Проверки интерфейса и сборки описаны в `VERIFICATION.md` после выполнения.
