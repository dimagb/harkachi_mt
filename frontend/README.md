# Диспетчерская трамваев Москвы

React + JavaScript + Vite. Экраны: `/login`, `/dashboard`, `/analytics`.

## Запуск

```sh
npm ci
npm run dev
```

Открыть http://localhost:5173. Vite проксирует `/api` на `http://localhost:8000`, как предусмотрено исходным контрактом. В клиенте используются только относительные `/api/...`; адрес бекенда в переменных окружения не нужен.

Для просмотра без бекенда: http://localhost:5173/login?demo=1. Деморежим явно обозначен в шапке и не включается автоматически при ошибках API. Чтобы выключить: удалить `tram-demo` из sessionStorage или открыть новую приватную сессию. Демо не выдумывает геометрию маршрутов и не отправляет административные команды. Выгрузка реального XLSX требует бекенд.

Вход — локальное переключение роли, API не защищается вымышленными токенами. Можно нажать «Войти в систему», не заполняя поля. Допустимые демонстрационные логин/пароль: dispatcher / dispatcher (не являются механизмом защиты). Административная форма доступна через меню пользователя после выбора роли «Администратор».

## Сборка и интеграция

```sh
npm test
npm run build
```

Содержимое `dist/` нужно положить в `service/static/` вашего бекенда. `assets/` сохраняется. SPA fallback для `/login`, `/analytics`, `/dashboard` реализуется бекендом по исходному документу. `Dockerfile.example` — пример многоступенчатой сборки для корня совместного репозитория, а не самостоятельный контейнер без бекенда.

## Контракт

Коэффициенты отправляются с debounce 180 мс. Для базы выполняется запрос без коэффициентов, для сценария — с коэффициентами. Значения `points` и события `network_events` повторно не умножаются. Геометрия сохраняет обе линии направлений и порядок `[lon,lat]`. XLSX получает те же фильтры и коэффициенты. Оговорка об оценочной разбивке берётся из `note`, остановки — из `name`, список отсутствующей геометрии — из `routes_without_geometry`.

Полные схемы `/meta`, `/factors`, `/scope`, `/forecast/compare`, `/forecast/routes` в присланном документе отсутствуют. Адаптеры поддерживают явно использованные формы: `{routes: [...]}`, `{factors: [...]}`, `{history:{points:[]},forecast:{points:[]}}`. После предоставления `/api/docs` необходимо сверить эти ответы с живым сервисом. При отсутствии метрики точности показывается «—», а не выдуманный процент. Погодная телеметрия и операции добавления вагонов не описаны в API: действия показывают честное уведомление и не объявляют команду отправленной.

Карта: MapLibre + [OpenFreeMap](https://openfreemap.org/quick_start/), центр Москвы. Спутниковые снимки OpenFreeMap не предоставляет, поэтому кнопка «Спутник» убрана по просьбе пользователя. Декоративные логотип и трамвай показываются из предоставленных пользователем изображений. Фон авторизации — отдельное изображение без нарисованной формы; поверх него отображается действующая HTML-форма.

Приоритет требований: уточнение пользователя о контракте и оценке; затем предоставленные пять макетов. Схемы компоновки и предложение изменить экран входа в исходном markdown не заменяют пользовательские макеты.

## Проверки

Автотесты контракта: периоды, високосный февраль, имена параметров, сохранение диапазонов коэффициентов, относительные запросы, ошибки API, отсутствие повторного применения событий сети. Проверки интерфейса и сборки описаны в `VERIFICATION.md` после выполнения.
