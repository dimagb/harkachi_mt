# Прогноз пассажиропотока трамвайных маршрутов Москвы

Решение трека «ИИ-прогноз загрузки трамвайных маршрутов»,
хакатон МТТЕХ, сентябрь 2026.

Прогнозирует число посадок по маршрутам и часам на два месяца вперёд
и отдаёт результат через веб-сервис с картой, агрегацией и выгрузкой.

**Лучший результат команды на лидерборде: 0.89447** при базлайне
организаторов 0.48. В зачёт идёт лучший результат за всё время.

**Сданный релиз: 0.88987.** Код, который его собирает, — в репозитории:
`python -m ml.build_release` (см. `README_ML.md`). Сам файл прогноза
`service/data/submission.csv` будет добавлен отдельным коммитом ML-команды;
до этого сервис стартует без прогноза. Разница между числами — маршрут 5:
в лучшем прогоне он построен cold start от аналога с даты запуска,
в сданном релизе — нули на весь период. Оба числа выше порога 0.88, то есть
максимальный балл за качество прогноза.

## Быстрый старт

### Прогноз

```bash
# разведка датасета — что внутри, какие ловушки
python ml/profile_data.py initial_data > report.txt

# сезонный базлайн: валидация и генерация submission.csv
python ml/baseline.py initial_data

# перебор гипотез для сравнения на лидерборде
python ml/baseline.py initial_data --sweep
```

Оба скрипта на чистой стандартной библиотеке — зависимостей нет.

### Сервис

```bash
cd service
docker compose up --build   # данные уже в service/data/, подкладывать ничего не нужно
# http://localhost:8000, API: http://localhost:8000/api/docs
```

### Нагрузочный тест

```bash
python service/loadtest/loadtest.py --url http://localhost:8000 \
    --duration 30 --threads 32
```

Цифры из вывода обязательно вписать в `service/README.md` — это прямое
требование ТЗ.

## Как устроено решение

Прогноз считается **пакетно** и сохраняется файлом в формате сдачи.
Веб-сервис читает готовые значения из памяти и агрегирует под запрос —
модель в момент обращения не работает.

Один расчёт даёт два результата: файл для лидерборда и данные для
дашборда. Расхождений между ними быть не может.

Модель прогноза:

```
прогноз = профиль(маршрут, день недели, час) × тренд × календарный коэффициент
```

Подробности: `docs/model.md`.

## Ключевые факты о задаче

- Целевая величина: число валидаций с `validation_result = 1`,
  гранулярность «маршрут × час»
- Метрика: `WAPE-score = max(0, 1 − Σ|y−ŷ|/Σy)`, баллы начисляются
  ступенями; верхняя ступень 0.88 пройдена
- Горизонт 61 день, **лаговых признаков не существует**
- В истории девять маршрутов; прогнозируется десять — маршрут 5 запущен
  16 декабря 2025 и в истории отсутствует. В сданном релизе он нулевой;
  cold start от аналога измерен (+0.0046), но не применён
- Телематики в датасете нет
- Сдача: ровно 14 640 строк, разделитель `;`

Полный список: `CLAUDE.md`.
